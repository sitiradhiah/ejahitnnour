# eJahit N'Nour

Sistem pengurusan tempahan jahitan yang dibangunkan sebagai projek akhir pelajar untuk sebuah kedai tempahan jahitan.

Projek ini melibatkan pembangunan oleh pelajar dengan bimbingan teknikal daripada **Siti Radhiah** dalam coding modul tertentu, reka bentuk database, reka bentuk sistem dan troubleshooting.

## Gambaran projek

Sistem ini menghimpunkan urusan tempahan, katalog pakaian dan maklumat pelanggan dalam sebuah aplikasi web. Repository ini mendokumentasikan hasil pembangunan projek pelajar serta proses pembelajaran dengan bimbingan teknikal.

## Modul dalam codebase

- Katalog pakaian dan kategori.
- Pendaftaran pengguna serta login dan logout.
- Pra-tempahan, pengurusan tempahan dan semakan status tempahan.
- Pengurusan maklumat pelanggan dan pekerja.
- Dashboard dan laporan tempahan.
- Aduan dan cadangan, testimonial serta pengumuman.

Senarai ini berdasarkan modul dan routes dalam repository; ia bukan pengesahan bahawa semua fungsi telah melalui testing untuk kegunaan production.

## Teknologi

- **PHP** — bahasa pengaturcaraan backend; keperluan dalam `composer.json` ialah `^8.1`.
- **Laravel 10** — framework aplikasi web; keperluan dalam `composer.json` ialah `^10.10`.
- **Blade** — template paparan Laravel.
- **Composer** — pengurusan dependencies PHP.

## Peranan dan sumbangan

### Pelajar — pembangunan projek akhir

Pelajar membangunkan sistem ini sebagai projek akhir dengan bimbingan teknikal sepanjang proses pembangunan.

## Struktur utama

| Direktori | Kandungan |
| --- | --- |
| `app/` | Controllers, models dan logik aplikasi. |
| `resources/` | Templates dan sumber paparan. |
| `routes/` | Routes aplikasi. |
| `database/` | Fail berkaitan struktur dan penyediaan database. |
| `public/` | Entry point web dan assets awam. |
